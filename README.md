# PRODUCT-CHECKOUT-IS-SUCCESSFUL-WITHOUT-PROPER-CREDIT-CARD-DETAILS
# DESCRIPTION
When I clicked on “Place Order” and inputted random number, the purchase was successful with this confirmation message “Thank you for your purchase.
# STEPS TO REPRODUCE:
Open demoblaze.com website
Login with a valid details “Username” and “Password”.
Add any product to the cart.
Navigate to the cart page.
Click on “Place Order”
Input a random name on “Name”
Input a random number on “Credit Card” e.g. “1”.
Click on “Purchase”.
Purchase is successful with a “Thank you for your purchase” page appearing.
# EXPECTED RESULT
The checkout page is supposed to show and error message when a random number is inputted for the credit instead of the right credit card details.

 # ACTUAL RESULT
 The purchase was successful with a random number inputted.
